# NestJS + Next.js E-Commerce Platform

Учебный fullstack-проект для исследования архитектурных подходов, инфраструктуры и сценариев развёртывания веб-приложений.

## Stack

### Backend

* NestJS
* PostgreSQL
* JWT Authentication

### Frontend

* Next.js
* TypeScript
* FSD (Feature-Sliced Design)
* Shadcn UI

### Infrastructure

* Docker Compose
* Docker Swarm
* Kubernetes
* Nginx
* Patroni

## Branches

### master

Базовая версия приложения.

### docker-swarm

Развёртывание через Docker Swarm с общим NFS-хранилищем.

### kubernetes

Эксперименты с развёртыванием в Kubernetes.

### patroni

Эксперименты с кластеризацией PostgreSQL через Patroni.

## Goals

* изучение NestJS и Next.js;
* исследование различных способов деплоя;
* работа с отказоустойчивыми базами данных;
* практика проектирования fullstack-приложений.
