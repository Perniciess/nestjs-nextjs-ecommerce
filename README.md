# Инструкция
Работает на 4ВМ. k3s+patroni.
Мой стек: Nest.js+Next.js+PostgreSQL+Nginx

# 1. Установка K3S
Нужно с флагами чтобы не использовал flannel

# 2. Установка Calico

# 3. Соединить ВМ в 1 подсеть.
Я использовал NAT+Внутренняя сеть. Пример файла `/etc/netplan/00-installer-config.yaml`
```
network:
  version: 2
  ethernets:
    enp0s3:
      dhcp4: yes
    enp0s8:
      dhcp4: no
      addresses:
        - 10.10.10.10/24
```
На остальных ВМ: 10.10.10.11, 10.10.10.12, 10.10.10.13
Переименовать хосты в удобные название, править `/etc/hosts` чтобы ВМ видели друг друга.

# 4. Ну там че-то с токеном нужно было объединить их в overlay сеть через k3s

# 5. Поставить метки на ВМ.
У меня были метки app, db. 
worker2=app, worker3=db, worker4=db

# 6. Установка Patroni
Качаем patroni, применяем манифест.
Сидим ждем пока все установится, проверяем через `kubectl get pods` или какая там команда. Я еще все поды с app выделил в namespace=ecommerce, а поды с БД в namespace=database

# 7. Настройка подключения к БД.
